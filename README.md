# 📚 Level 1 – HTML, CSS & JavaScript Fundamentals

The first level focuses on understanding the fundamentals of frontend development.

### 1️⃣ Simple Webpage

Created a basic webpage containing:

* Heading
* Paragraph
* Image
* CSS styling

This task helped me understand the basic structure of an HTML document and how CSS can be used to style webpage elements.

### 2️⃣ Interactive Button

Created a button using HTML and JavaScript that changes its background color when clicked.

**Concepts learned:**

* JavaScript functions
* DOM element selection
* Event handling
* Dynamic CSS changes


### 3️⃣ Greeting Alert

Created a JavaScript-based greeting feature that detects the current time and displays:

* 🌅 Good Morning
* ☀️ Good Afternoon
* 🌙 Good Evening

This helped me practice JavaScript conditions and working with the `Date` object.


### 4️⃣ Basic Calculator

Created a simple calculator that accepts two numbers and calculates their sum.

**Features:**

* 🔢 Number input
* ➕ Addition operation
* 📊 Dynamic result display


### 5️⃣ Simple Form

Created a basic form containing:

* Text input
* Submit button
* Styled form container

This task helped me understand HTML forms and CSS-based component styling.


### 6️⃣ Navigation Menu

Created a simple navigation bar containing:

* 🏠 Home
* ℹ️ About
* 📞 Contact

CSS was used to create the layout, spacing, colors, and hover effects.


# 📱 Level 2 – Responsive Web Design & Frameworks

The second level focuses on responsive design and frontend frameworks.

### 1️⃣ Responsive Card using Bulma

Created a responsive card component using the **Bulma CSS framework**.

The card contains:

* 🖼️ Image
* 📝 Title
* 📄 Description

The component adapts to different screen sizes including mobile, tablet, and desktop.


### 2️⃣ Responsive Grid using Bootstrap

Implemented a responsive grid layout using **Bootstrap**.

The layout demonstrates how columns can automatically adjust according to different screen sizes.

**Concepts practiced:**

* Bootstrap container
* Bootstrap rows
* Responsive columns
* Mobile and desktop layouts


### 3️⃣ Responsive Webpage using CSS Media Queries

Created a webpage that changes its layout and styling according to the screen size.

The design uses CSS `@media` queries to provide a better experience on smaller devices.

**Responsive features include:**

* 📱 Mobile layout
* 💻 Desktop layout
* 🔤 Adaptive font sizes
* 🖼️ Responsive images


### 4️⃣ Mobile-Friendly Navigation Menu

Created a responsive navigation menu that changes into a **hamburger menu ☰** on smaller screens.

**Features:**

* Desktop navigation
* Mobile hamburger menu
* Responsive layout
* CSS-only menu toggle
